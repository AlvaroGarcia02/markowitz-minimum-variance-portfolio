# Minimum Variance Portfolio with Markowitz's Model

**Construcción de una cartera de mínima varianza mediante el modelo de Markowitz**

## Overview

This project builds a minimum variance portfolio from four large-cap U.S. stocks from different sectors — Apple (AAPL), The Coca-Cola Company (KO), JPMorgan Chase & Co. (JPM) and Chevron Corporation (CVX) — using Markowitz's portfolio theory. Daily closing prices for 2017–2018 are downloaded from Yahoo Finance, transformed into log returns, analyzed descriptively, and used to estimate the covariance matrix and the optimal weights that minimize portfolio risk.

## Methodology

- **Data:** daily closing prices from Yahoo Finance (2017-01-01 to 2018-12-31), downloaded with `quantmod`.
- **Returns:** daily log returns, $R_t = \ln(P_t / P_{t-1})$.
- **Descriptive analysis:** summary statistics, skewness and violin/box plots for each asset.
- **Distribution fitting:** goodness-of-fit tests to identify the best-fitting distribution for each asset's returns.
- **Optimization:** sample covariance matrix $\Sigma$ and minimum variance weights

$$\mathbf{w}_c = \frac{\Sigma^{-1}\mathbf{1}}{\mathbf{1}^\top \Sigma^{-1}\mathbf{1}}$$

- **Evaluation:** comparison of the minimum variance portfolio against an equally weighted portfolio.

## Results

**Minimum variance portfolio weights**

| Asset | Weight |
|---|---|
| Apple (AAPL) | 8.85% |
| Coca-Cola (KO) | 67.01% |
| JPMorgan Chase (JPM) | 13.33% |
| Chevron (CVX) | 10.81% |

**Portfolio variance**

| Portfolio | Variance |
|---|---|
| Equally weighted (25% each) | 0.0000717 |
| Minimum variance | **0.0000496** |

The minimum variance portfolio reduces variance by about 31% compared with the equally weighted portfolio, and its variance is lower than that of any individual asset. Coca-Cola receives the largest weight because it has the lowest individual variance and low covariances with the other assets.

## How to reproduce

1. Download this repository (**Code → Download ZIP**) and unzip it.
2. In R, set the working directory to the root folder and install the packages:
```r
   install.packages(c("quantmod", "openxlsx", "ggplot2"))
```
3. Run `R/minimum_variance_portfolio.R`. Data are downloaded directly from Yahoo Finance.

## Resumen en español

Construcción de una cartera de mínima varianza con el modelo de Markowitz a partir de cuatro activos de sectores distintos: Apple, Coca-Cola, JPMorgan Chase y Chevron. Se emplean precios de cierre diarios de Yahoo Finance (2017–2018) para calcular retornos logarítmicos, realizar un análisis descriptivo y de ajuste de distribuciones, estimar la matriz de varianzas y covarianzas y obtener las ponderaciones óptimas. La cartera resultante (67 % en Coca-Cola) reduce la varianza en cerca de un 31 % frente a la cartera equiponderada.
